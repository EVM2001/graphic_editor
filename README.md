Целью данного проекта была разработка программы объектно-ориентированного графического редактора, обеспечивающего выполнение следующих основных функций:  
1.	Выбор, размещение на экране и визуализация примитивов;  
2.	Синтез более сложных фигур с помощью теоретико-множественных операций (ТМО) над примитивами;  
3.	Выделение любого объекта, выведенного на экран, и выполнение над ним любой последовательности геометрических преобразований в интерактивном режиме;  
4.	Выделение любого объекта на экране и его удаление.  

В данном проекте были реализованы:  
Примитивы:  
•	Кривая Безье;  
•	Равнобедренный треугольник;  
•	Флаг.  
Геометрические преобразования:  
•	Поворот вокруг центра фигуры на произвольный угол;  
•	Масштабирование по оси X относительно центра фигуры;  
•	Зеркальное отражение относительно прямой общего положения.  
ТМО:  
•	Пересечение;  
•	Разность
